# Features

Functional specs, one per feature ID (`type: Feature Spec`), grouped by bounded context.

| Context | Prefix | Folder |
|---|---|---|
| Hedges | `HEDGE` | `hedges/` |
| Loans | `LOAN` | `loans/` |
| Stress test | `STRESS` | `stress-test/` |
| Monthly computations | `CALC` | `monthly-calc/` |
| Graphs / visualisation | `GRAPH` | `graphs/` |
| Admin | `ADMIN` | `admin/` |
| Integrations & Kafka | `INT` | `integration/` |

Template: `_template.md`. Rules: `.github/instructions/features.instructions.md`.
Index of all specs is generated by `scripts/build-index.ps1` into each folder's `index.md`.
