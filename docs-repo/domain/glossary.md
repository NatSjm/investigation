# Glossary

Single source of terminology. One line per term, alphabetical. Agents MUST use these terms.
The repo is written in **English**; the `Czech (cs)` column is the controlled translation used when migrating
Confluence pages (cs -> en) and when publishing back to Confluence (en -> cs). Agents translate terms only via this
table; anything not listed here is added first, never translated ad hoc.

| Term | Czech (cs) | Definition | Also known as (do not use) |
|---|---|---|---|
| Advisor | poradce | Bank employee running the client meeting and creating proposals | RM, dealer |
| Client | klient | Corporate customer of the bank owning loans/hedges | customer |
| Hedge proposal | návrh zajištění | A draft derivative (e.g. IRS) offered to a client to hedge a loan | offer, deal draft |
| Loan | úvěr | Financing product with schedule; can be floating or fixed | credit, facility |
| Monthly computation | měsíční výpočet | Batch producing per-month cashflows/valuations for all instruments | monthly run |
| Notional | nominál | Reference amount of a derivative | principal (for derivatives) |
| Stress test | zátěžový test | Recomputation under shocked market scenarios | what-if |
| Tenor | tenor | Duration of an instrument | maturity (use for the date) |
