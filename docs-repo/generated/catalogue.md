# Catalogue

> Generated by `scripts/gen-catalogue.py` on 2026-10-20. Do not edit by hand.

How to use: a request in free text names none of these IDs. Read this page once, decide which lines the request is
about (several contexts and several kinds are normal), then build ONE pack with a `--task` per subject:
`python3 scripts/context-pack.py --task <spec ID> --task <calculation> --task flows/<name>.md --task context:<name>`.
A part of the request that matches no line is **new** work: add `--task context:<name>` for the context it belongs to;
that pack section lists what the context already has (endpoints, tables, calculations, classes) to place it next to.
Terms people use differently are mapped in the glossary section at the end. Definitions, formulas and rules are
not here: they are in the files each line points to.
